## App name

JiraTack

## Tagline

Drop pins on web pages. Turn them into Jira tickets.

## Short description

JiraTack lets QA and product teams pin issues directly on the pages they are
reviewing. Click a spot on the page, describe the problem, and JiraTack creates
a Jira ticket with the page URL, pin position, and optional screenshot and
console output.

## Highlights

- Pin issues on any web page with a bookmarklet — no browser extension.
- Creates Jira tickets with page URL, position, selector, screenshot, and
  console output.
- Canvas dashboard aggregates pins across projects.
- Epic and issue panels show related pins without leaving Jira.
- Two token scopes: write (create pins) and view (read-only review).
- Revocable canvas tokens with 30-day expiry.

## Permissions justification

- `read:jira-work`, `write:jira-work` — read issue data and create/update
  JiraTack tickets.
- `read:jira-user` — resolve assignees and participants.
- `manage:jira-project` — provision custom fields and project settings.
- `manage:jira-configuration` — add JiraTack fields to Jira screens.
- `storage:app` — store installation configuration and canvas tokens.
